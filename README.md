# Exact Covariance Structure and Efficient Computation for L-Comoments

This repository is intended to contain the computational code and reproducibility materials associated with the research paper:

**Exact Covariance Structure and Efficient Computation for L-Comoments**

**Authors:** Palakorn Seenoi and Jeong-Soo Park

## Overview

The associated research studies the exact finite-sample covariance structure of sample L-comoments, covariance estimation, and efficient computational methods.

The planned computational materials will support the verification and reproduction of the numerical experiments reported in the paper.

## Repository Status

This repository is currently under preparation.

Source code, testing procedures, and instructions for reproducing the numerical results will be added after implementation checks and validation are completed.

## Planned Contents

- `R/` — R functions for L-comoment and covariance calculations.
- `tests/` — Tests comparing computational results with direct calculations on small samples.
- `examples/` — Scripts illustrating the use of the proposed methods.
- `results/` — Selected outputs needed to reproduce the numerical experiments.

The final directory structure will depend on the validated implementation.

## Reproducibility

The reproducibility instructions will specify the required software, how to run the scripts, and how to compare the computed results with the reported tables and figures.
